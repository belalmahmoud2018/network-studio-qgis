description=Utility network management for QGIS: water, sewer, storm, gas, electricity, fiber, telecom, district cooling and roads, in GeoPackage, SpatiaLite, File Geodatabase and PostgreSQL / PostGIS.
about=Choose the network type first and Network Studio creates the classes, asset groups, asset types, terminals, tiers and connectivity rules for it. Store the network in GeoPackage, SpatiaLite, File Geodatabase or PostgreSQL / PostGIS (several users editing at the same time). Import your existing layers with automatic asset group matching, or import from ArcGIS (utility network classes, associations, Network Analyst streets). Prepare the network (close gaps, add missing vertices), validate it (dangles, gaps, rule violations, islands without a source and more), trace it (connected, upstream, downstream, isolation with the valves / switches to close, shortest path, loops, subnetwork), manage subnetworks and controllers, associations and automatic service connections to customers. Also included: smart editing, edit history, work orders, criticality and risk, cost estimate, longitudinal profiles, network diagrams, map book PDF, EPANET / SWMM export with results on the map, QField and web publishing, reports, and export to an ArcGIS utility network asset package. Concepts follow the ArcGIS utility network; the network itself works in QGIS.
