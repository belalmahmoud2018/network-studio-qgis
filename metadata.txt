description=Utility network tools for QGIS: water, sewer, storm, gas, electricity, fiber, telecom, district cooling and roads, in GeoPackage, SpatiaLite and File Geodatabase.
about=Choose the network type first and Network Studio creates the classes, asset groups, asset types and connectivity rules for it. Import your existing layers with automatic asset group matching, prepare the network (close gaps, add missing vertices), validate it (dangles, gaps, missing vertices, rule violations, islands without a source), trace it (connected, upstream, downstream, isolation with the valves / switches to close, shortest path, loops, subnetwork), update subnetworks, create containment / attachment associations and draw service connections to customers automatically. Everything is stored inside the data file. Asset groups and types are also written for the Subtypes and Domains Manager plugin. Concepts follow the ArcGIS utility network; the network itself works in QGIS only.
